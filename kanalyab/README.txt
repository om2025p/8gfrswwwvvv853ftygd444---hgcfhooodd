کانال‌یاب — جست‌وجوی کانال‌های تلگرام
=====================================

وب‌اپلیکیشن تک‌فایل و آفلاین‌پسند برای جست‌وجو در فهرست کانال‌های عمومی تلگرام.

دسترسی
------
https://om2025p.github.io/8gfrswwwvvv853ftygd444---hgcfhooodd/kanalyab/

فایل‌ها
-------
index.html      پنل کامل (HTML + CSS + JS در یک فایل)
manifest.json   تنظیمات نصب روی موبایل (PWA)
icon.svg        آیکون برنامه
channels.json   فهرست کانال‌ها برای مصرف برنامه‌نویسی
channels.csv    همان داده در قالب CSV (اکسل)

قابلیت‌ها
--------
- جست‌وجوی زنده روی نام، یوزرنیم، توضیحات و آیدی عددی
- فیلتر خط/زبان: فارسی، لاتین، فینگلیش، روسی، عربی
- فیلتر یوزرنیم‌دار و لینک‌دار
- مرتب‌سازی بر اساس اعضا، تاریخ افزودن، تعداد محتوا
- شمارنده پست/عکس/فیلم/متن با چک‌باکس جداگانه
- خروجی CSV از نتیجه فیلترشده
- لینک کلیک‌پذیر مستقیم به هر کانال
- پنل کشویی برای صفحه‌های کوچک
